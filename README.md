# Aegis

Aegis App is a comprehensive, cross-platform application designed to streamline interactions between clients and freelancers. It serves as a unified workspace where users can manage their professional profiles, verify their status, track ongoing and completed projects, and securely handle financial transactions like wallet withdrawals. 

## 🚀 Tech Stack

This project is built using a modern, decoupled architecture:

*   **Frontend (Flutter)**: The user interface is developed with Flutter, allowing the application to compile natively across Android, iOS, Web, macOS, Windows, and Linux from a single codebase. 
*   **Backend (Python)**: The server-side logic and database models are powered by a Python backend environment. 

## ✨ Key Features

*   **Universal Compatibility**: Native support for mobile, desktop, and web environments.
*   **Dual-Role Profiles**: Tailored interfaces and dashboards depending on whether the user is logged in as a Client or a Freelancer.
*   **Trust & Verification**: Built-in status indicators for verified users (e.g., Verified Student).
*   **Wallet Management**: An integrated dashboard for users to track their total earnings, available balance, and initiate withdrawals.
*   **Project Tracking**: Real-time statistics on completed projects and overall ratings.
